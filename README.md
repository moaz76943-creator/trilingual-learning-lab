# Trilingual Learning Lab

تطبيق تفاعلي لتعلم ثلاث لغات بالتوازي (العربية - الألمانية - الإنجليزية).
مبني بمنهجية البناء التراكمي التدريجي، ومصمم ليعمل دون اتصال بالإنترنت (Offline-first).

## اللغات المدعومة
* العربية (Arabic)
* الألمانية (German)
* الإنجليزية (English)

## مسار العمل
تطوير واختبار خفيف عبر Termux و Python، وبناء Android عبر GitHub Actions.
