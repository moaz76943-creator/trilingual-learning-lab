# المعمارية الأساسية (V2 Foundation)

## مبادئ التصميم:
1. **Single Source of Truth**: ملفات المحتوى اللغوي منظمة بمفاهيم ثابتة المعرّف (Concept IDs).
2. **Offline First**: لا يعتمد التطبيق على خوادم خارجية أو اشتراكات خارجية لتصفح المفردات.
3. **Independent UI**: نموذج البيانات مفصول تمامًا عن شاشات العرض وقاعدة بيانات تقدم المستخدم.
4. **Stable Lexemes**: لكل لغة حقولها الخاصة (مثل الـ Artikel والجمع للألمانية، والتشكيل للعربية).
